# AI Resume Job Search Platform

## About the Project
The AI Resume Job Search Platform is designed to help users build resumes, analyze their skills, identify skill gaps, and find suitable job opportunities.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Node.js
- **Database:** MySQL

## Main Features
- Resume building
- Resume analysis
- Skill gap analysis
- Job search

## Project Goal
The goal of this project is to help job seekers improve their resumes, understand their skills, and identify suitable job opportunities.

## Team Project
This is a collaborative academic project developed by our team.
